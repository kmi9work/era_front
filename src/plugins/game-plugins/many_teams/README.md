# Плагин many_teams (era_front)

Клиент мастеров для режима «много команд». Данные — из движка `many_teams`
(`/many_teams/...`), своих расчётов плагин не делает.

Включение: `VITE_ACTIVE_GAME=many-teams` (написание `many_teams` тоже
принимается).

## Что меняет

Плагин не копирует экраны ядра, а подменяет компоненты маршрутов
(`router.getRoutes()` → `record.components.default`) и подмешивает компоненты
новых политдействий в диспетчер ядра.

| Экран | Что добавлено |
|---|---|
| `/dashboard` | таблица отношений (диапазон выбора стран) + блок «Государства игроков» с подтверждением выбора (п. 7) |
| `/aux` (окно «Гильдии») | табло мастеров: таймер сверху + таблица всех гильдий игры — разрешение на строительство/производство в текущем государстве, эмбарго, ресурсы на его территории |
| `/aux` (окна «Результаты всех команд») | два табло для зала игры: «общий зачёт» (экономика — стоимость предприятий в государстве, политика — очки влияния) и «личный зачёт» (знать по влиянию, гильдии по капиталу на игрока) — места по всем командам сразу |
| `/economics` (вкладка «Дашборд») | «Эмбарго по гильдиям» — обзор (п. 9), «Добыча по гильдиям» — все гильдии × текущая страна (п. 4, п. 5) |
| политдействия | `conduct_intelligence`, `undermine_stability`, `undermine_relations`, `set_guild_permission`, `lift_guild_embargoes` (п. 11, п. 2, п. 10) |

## Государства игроков (п. 7)

Блок «Государства игроков» на «Дашборде» повторяет галочки ядра, но изменение
вступает в силу только по кнопке **«Подтвердить выбор»**: до этого плашка
сообщает, что в игре действует прежний набор. «Отменить изменения» возвращает
подтверждённый набор с бэкенда. Пустой набор означает «ограничение не задано» —
гильдии могут строить в любом государстве (иначе на чистой базе нельзя строить
ничего).

Подтверждённый набор перезаписывается в `localStorage['dashboard_countries']`,
поэтому галочки ядра и блок плагина показывают одно и то же.

## Эмбарго (п. 9, п. 10)

Направление — как в правилах игры: накладывает **иностранное государство** (строка в
блоке «Отношения»), цель — **гильдия любого государства игры**: в диалоге есть выбор
государства, по умолчанию показываются гильдии государства из ячейки (текущего).
Накладывать может только государство, торгующее на рынке (признак `trades_on_market`
в `/countries.json`): сейчас это Орда, Ливония, Швеция, Литва, Казань и Крым, у Руси и
русских княжеств своих товаров на «Рынке» нет.

* кнопка эмбарго в ячейке пары (`components/PairEmbargoButton.vue`) есть только у
  торгующих государств; клик открывает модалку `components/GuildEmbargoDialog.vue`:
  выбор государства (включая «Все государства игры») и переключатель на каждую гильдию
  в таблице «Гильдия / Государство / Эмбарго», кнопки «На все гильдии «страна»» и
  «Снять со всех в «страна»» — они работают по выбранному в диалоге государству;
  данные берутся из `GET /many_teams/guild_embargoes` без `target_country_id`
  (все гильдии игры), поэтому цель эмбарго не ограничена текущей страной;
* ячейка пары — общий `PairRelationsCell.vue` ядра, поэтому одна правка даёт оба
  экрана: «Информация о стране» → «Отношения» и «Дашборд» (матрица);
* караван гильдии под эмбарго сервер не блокирует: карточку «Контрабанда» проверяет
  мастер в окне «Есть карточка контрабанды!» на «Рынке» (раньше движковый
  `CaravanClassExtensions` отказывал без карточки — проверка убрана по решению
  заказчика); маршрут через Вятку считается как раньше;
* «Снять всё» — действие Великого князя по технологии «Заморская торговля»,
  доступно в «Политических действиях» (п. 10). Диалог спрашивает статус технологии
  у движка (`GET /many_teams/guild_embargoes/lift_all_availability`): если в текущем
  государстве она не открыта, показывается предупреждение «Действие запрещено…»,
  но ни экран, ни бэкенд действие не блокируют — флаг `overseas_trade_open` уходит
  в params политдействия, клиент пишет об этом в сообщении об успехе. Панель на
  «Экономике» — только обзор («кто на кого наложил»), без редактирования.

## «Рынок»: подсветка эмбарго

На вкладке «Рынок» раздела «Экономика» эмбарго тоже считается **по гильдии**, а не
по стране: гильдия выбирается до открытия рынка, и кнопки государств подсвечиваются
по карте «страна → наложено эмбарго на эту гильдию».

* движок: `GET /many_teams/guild_embargoes/market?guild_id=` отдаёт
  `countries[].embargoed` для выбранной гильдии (`views/EconomicsPage.vue`);
* ядро (`views/pages/economics/Exchange.vue`) принимает необязательный пропс
  `embargoCountries` (карта `{ countryId: true }`) и использует его вместо
  странового флага `params["embargo"]`; плагин передаёт карту и слушает
  `@guild-selected`, чтобы перечитать её при смене гильдии;
* в базовой игре пропс не передаётся — ядро работает по-прежнему по страновому флагу;
* диалог «Контрабанда» на «Рынке» берёт заголовок/текст из пропсов
  (`embargoDialogTitle`, `embargoDialogText`): в many_teams — «Эта страна наложила
  эмбарго на гильдию!».

## Строительство и работа предприятий (п. 0-4)

Запрет один и закрывает одновременно строительство предприятия и работу уже
построенного; категория предприятия (добывающее/перерабатывающее) роли не играет.
Таблица **всех гильдий игры** (Москва — Забавники, Каменщики, Пивовары; Новгород —
Плотники, Кузнецы, Каменотёсы) с одной колонкой-переключателем «строительство и
работа разрешены на территории текущего государства»: страна решает только за свою
землю. По умолчанию открыто в стране гильдии и закрыто в остальных; переключатель
вызывает действие Казначея, ячейка помечается «изменено вручную» или «по умолчанию».
Заголовки «Гильдия» и «Государство гильдии» сортируют таблицу (повторный клик —
обратный порядок; по умолчанию — государство, внутри государства — название гильдии).

Запрет — только предупреждение: сервер предприятие не блокирует (п. 4).

## Окно «Гильдии» на «Служебном»

Экран выводится на большой экран мастерами: верхняя четверть — обычный таймер
расписания (тот же компонент `views/pages/aux/TimerScreen.vue`, что на окне
«Таймер»), нижние три четверти — таблица **всех гильдий игры**:

| Колонка | Источник |
|---|---|
| Гильдия (и государство гильдии с флагом) | `guilds` |
| Разрешено строительство/производство на территории текущего государства | `ManyTeams::GuildExtractionPermission` — то же правило, что проверяет валидация предприятия |
| Страны, введшие эмбарго | `ManyTeams::GuildEmbargo` (кто наложил на гильдию) |
| Ресурсы на территории текущего государства | выпуск (`max_product`) предприятий гильдии, участок которых лежит в регионе этого государства; **только значки, без количества** |
| Товарооборот по странам (за всю игру) | караваны гильдии за все годы, сумма \|вывоз\| + \|ввоз\| по каждой стране; ограбленные не считаются; в ячейке герб + число |

* движок: `GET /many_teams/guilds_overview?country_id=` → `ManyTeams::GuildsOverview`
  (`engines/many_teams/app/services/many_teams/guilds_overview.rb`), только чтение;
* окно объявляется плагином в реестре `aux_screens` — ядро
  (`ScreenManagement.vue`, `Screen.vue`) рисует карточку выбора и передаёт экрану
  таймер пропсом; без регистрации список окон в базовой игре не меняется;
* данные обновляются раз в 15 секунд и при смене государства;
* значки рисует общий `src/components/ResourceIcons.vue` с новым пропсом
  `show-count` (по умолчанию количество по-прежнему печатается).

## Разведка (п. 11)

`views/actions/conduct_intelligence.vue` показывает четыре пункта с ценами
(1 000 / 1 000 / 3 000 / 3 000), выбор региона и команды-соперника; отчёт
приходит с бэкенда в `params.report` политдействия. `undermine_relations.vue`
по умолчанию подставляет зарубежное государство первым.

Влияние Тайного советника начисляет бэкенд (`InfluenceItem`) при успехе:
разведка порядка и отношений +1, разведка дохода знати и технологий +2,
подрыв стабильности и отношений +3. Диалоги показывают бонус до выполнения,
а после — `influence_delta` из `params` политдействия.

Регион в пунктах «Общественный порядок в регионе» и «Подорвать стабильность»
(`undermine_stability.vue`) выбирается только из **стран-соперников** — государств
игроков, подтверждённых на «Дашборде», кроме текущего (`GET /many_teams/intelligence/targets`,
поле `regions` с `country_name`); в подписи пункта видно государство региона.
Доход знати в отчёте считается формулой ядра `Player#income(<государство знати>)`
(поселения, постройки, надбавки и ручные `income_items`), а не только по
`income_items` — поэтому нулей больше нет.

## Точка расширения в ядре

`src/views/pages/politics/PoliticalAction.vue` подмешивает в свой `compMap` все
ключи `componentRegistry`, оканчивающиеся на `.action_components`. Это
универсальная точка расширения: следующий игровой плагин добавляет свои
компоненты действий, не правя ядро повторно.

`src/components/PairRelationsCell.vue` берёт кнопку эмбарго из registry по ключу
`pair_relations_embargo` (пропсы `country`, `partner-country`, событие `reload`).
Плагин регистрирует `components/PairEmbargoButton.vue`; без регистрации ядро
рисует прежнюю кнопку-переключатель `set_embargo`, поэтому базовая игра работает
как раньше. Одна регистрация закрывает оба экрана: «Информация о стране» →
«Отношения» и матрицу «Дашборда».
