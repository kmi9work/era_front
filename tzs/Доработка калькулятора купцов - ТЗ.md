# Приложение "Кошелек ресурсов" (доработка калькулятора купцов)

Приложение "Калькулятор купцов" (/home/mic/learn/era/era_front/merchant_mobile_helper.html) нужно переделать в приложение "ЭП: Кошелёк ресурсов" на PWA в текущей ветке bucket проекта era_front.

# Дополнительный функционал

Раздел "Кошель": У игрока есть ресурсы. Это картинка и количество. Ресурсы могут быть переданы другим игрокам.

# Аутентификация

После запуска приложения нужно выбрать игрока, который будет играть с этого мобильного телефона. Этот выбор сохраняется в приложении. Сменить игрока после первого выбора нельзя.

# Инфраструктура

Приложение написано как PWA. 
- Id игрока хранится на устройстве
- Количество ресурсов хранится на бэке и синхронизируется с приложением.
- Иконки ресурсов есть в приложении
 
Бэк с API: https://epoha.igroteh.su/backend/ (бэк в директории /home/mic/learn/era/eraofchange/)
Эндпоинты (нужно узнать из проекта /home/mic/learn/era/eraofchange/):
- Список игроков (модель Player)
- Количество ресурсов и их типы у выбранного игрока (Player has_many :resource_items)

# Действия игрока

**Передать ресурсы** - ресурсы передаются другому игроку:
1. Игрок А выбирает "Передать"
2. Игрок А выбирает "Кому" (пользователь Б)
3. Игрок А собирает корзину ресурсов, которые надо передать (не больше, чем у него есть).
4. Игрок А видит экран передачи, где указано кому и сколько ресурсов передаётся и подтверждает передачу.
5. Количество ресурсов у игрока А уменьшается на Корзину. Количество ресурсов у игрока Б увеличивается на Корзину.
